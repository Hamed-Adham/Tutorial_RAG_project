## چگالی

چگالی یکی از ویژگی‌های مهم مواد است که به ما کمک می‌کند مواد مختلف را از یکدیگر تشخیص دهیم. چگالی هر ماده برابر است با جرم واحد حجم آن ماده. به عبارت دیگر:

چگالی = جرم ÷ حجم

یا به صورت نمادی:

ρ = m ÷ V

که در آن:
- **ρ** (رو): چگالی بر حسب کیلوگرم بر مترمکعب (kg/m³)
- **m**: جرم بر حسب کیلوگرم (kg)
- **V**: حجم بر حسب مترمکعب (m³)

چگالی یک ویژگی ذاتی ماده است؛ یعنی به مقدار ماده بستگی ندارد. برای مثال، چگالی آب خالص در دمای ۴ درجهٔ سلسیوس برابر ۱۰۰۰ کیلوگرم بر مترمکعب است، چه یک قطره آب باشد چه یک دریاچه.

جدول زیر چگالی برخی مواد رایج را در دمای اتاق نشان می‌دهد:

| ماده | چگالی (kg/m³) |
|------|--------------|
| هوا | ۱/۲۹ |
| چوب‌پنبه | ۲۴۰ |
| چوب | ۵۰۰ تا ۹۰۰ |
| آب | ۱۰۰۰ |
| آلومینیوم | ۲۷۰۰ |
| آهن | ۷۸۷۴ |
| مس | ۸۹۶۰ |
| سرب | ۱۱۳۴۰ |
| جیوه | ۱۳۵۴۶ |
| طلا | ۱۹۳۰۰ |

همان‌طور که از جدول مشاهده می‌کنید، چگالی مواد مختلف با یکدیگر تفاوت زیادی دارد. این تفاوت در چگالی دلیل شناور ماندن برخی اجسام بر روی آب و فرو رفتن برخی دیگر در آن است.

## اندازه‌گیری چگالی

برای اندازه‌گیری چگالی یک جسم، باید جرم و حجم آن را اندازه بگیریم. جرم را می‌توان با ترازو اندازه گرفت. اندازه‌گیری حجم به شکل جسم بستگی دارد:

- **اجسام منظم** (مانند مکعب، استوانه): با اندازه‌گیری ابعاد و استفاده از فرمول هندسی حجم را محاسبه می‌کنیم.
- **اجسام نامنظم**: از روش جابه‌جایی آب استفاده می‌کنیم؛ جسم را درون آب فرو می‌بریم و حجم آب جابه‌جاشده را اندازه می‌گیریم.

<experiment>

### آزمایش کنید

**هدف:** اندازه‌گیری چگالی چند جسم مختلف

**وسایل مورد نیاز:** ترازو، استوانهٔ مدرج، آب، چند جسم با اشکال مختلف (مانند سنگ، تکه فلز، تکه چوب)

**روش کار:**

۱. جرم هر جسم را با ترازو اندازه بگیرید و یادداشت کنید.
۲. مقداری آب درون استوانهٔ مدرج بریزید و حجم اولیهٔ آب را بخوانید و یادداشت کنید.
۳. جسم را به آرامی درون استوانهٔ مدرج فرو ببرید (برای اجسامی که روی آب شناور می‌مانند، از سیم نازکی برای فرو بردن آن‌ها استفاده کنید).
۴. حجم جدید آب را بخوانید. اختلاف دو عدد، حجم جسم است.
۵. با استفاده از فرمول چگالی = جرم ÷ حجم، چگالی هر جسم را محاسبه کنید.
۶. نتایج را در جدول زیر یادداشت کنید.

| جسم | جرم (g) | حجم (cm³) | چگالی (g/cm³) |
|-----|---------|-----------|--------------|
|     |         |           |              |
|     |         |           |              |
|     |         |           |              |

**نتیجه‌گیری:** چگالی اجسام مختلف را با یکدیگر مقایسه کنید. آیا جسمی که چگالی آن از آب بیشتر است در آب فرو می‌رود؟

تصویر آزمایش: یک استوانهٔ مدرج شفاف روی میز قرار دارد که درون آن آب ریخته شده است. یک دانش‌آموز با دقت یک سنگ کوچک را درون استوانه فرو می‌برد تا حجم آب جابه‌جاشده را اندازه بگیرد. در کنار استوانه، یک ترازوی دیجیتال دیده می‌شود که جرم جسم را نشان می‌دهد.
